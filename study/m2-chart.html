Модуль 2 · Чтение графика

Карта рынка — структура, уровни, зоны

Как «читать» чистый график: где мы в тренде, откуда крупный входит и где лежит ликвидность толпы. Свеча-триггер — на отдельном листе.

🟠 рост / бычье движение 🟣 падение / медвежье движение
1

Структура рынка (2.1)

Рынок «дышит»: импульс (направленное движение) + коррекция (откат, передышка). Тренд — это лестница из ступенек, а не прямая линия.

Откат ≠ разворот — главное различие всего модуля. Пока лестница идёт в одну сторону — тренд жив.

🟠 Аптренд = HH + HL

  • HH — higher high (каждый пик выше)
  • HL — higher low (каждая ямка выше)
  • Покупатели сильнее — берём только лонги
Ступеньки идут ВВЕРХ

🟣 Даунтренд = LH + LL

  • LH — lower high (каждый пик ниже)
  • LL — lower low (каждая ямка ниже)
  • Продавцы сильнее — берём только шорты
Ступеньки идут ВНИЗ
Флэт буквами HH/HL НЕ размечается — это язык тренда. Флэт = две горизонтали + EQH / EQL (равные верхи/низы = ликвидность). Событие структуры считаем только по ЗАКРЫТИЮ свечи за уровнем — прокол тенью не считается.
2

BOS и CHoCH — слом структуры (2.2)

BOS — Break of Structure

  • Слом ПО тренду = продолжение
  • Пробили HH в аптренде / LL в даунтренде
  • Лестница шагнула дальше
ломает «потолок» ПО ходу движения

CHoCH — Change of Character

  • Слом ПРОТИВ тренда = 1-й признак разворота
  • Пробили последний HL в аптренде / LH в даунтренде
  • Выбита опора тренда
выбивает «опору» ПОД движением

3

Уровни и полярность (2.3)

Уровень = след крупных денег (недоисполненные заявки + память крупного + стопы толпы), а не просто линия. Поддержка — пол (отбой вверх), сопротивление — потолок (отбой вниз).

Уровень — это ЗОНА, а не нитка. Ведём по кластеру тел свечей, хвосты торчат.

Контринтуитив: первое касание самое сильное; частые тесты СЪЕДАЮТ заявки и ослабляют уровень.

💠 Полярность — сердце урока
Пробитый уровень меняет роль: сопротивление ↔ поддержка. Выбитые продавцы закрываются/переворачиваются — потолок становится полом.

4

Зоны спроса/предложения и ликвидность (2.4)

Уровень (2.3) = память касаний. Зона (2.4) = основание импульса. Уровень — горизонталь по кластеру касаний; зона — прямоугольник у базы резкого, почти вертикального движения (ушла резко и ОДИН раз).

🟠 Зона спроса (Demand)

  • База ПОД сильным импульсом вверх
  • Здесь крупный купил
  • Ждём отсюда лонг
рисуем прямоугольник по базовой свече

🟣 Зона предложения (Supply)

  • База НАД сильным импульсом вниз
  • Здесь крупный продал
  • Ждём отсюда шорт
тянем зону вправо как барьер

Контринтуитив (как с уровнем): свежая, не тестированная зона — самая сильная; каждый возврат её ослабляет (заявки исполняются, топливо кончается).

Круглое число = цена с нулями (BTC 100k/90k/70k, ETH 4000/3000). Психология толпы: магнит + барьер + гнездо стопов. Это усилитель (конфлюенс), НЕ синоним сильного уровня.

Ликвидность = скопление стопов: под равными минимумами (equal lows, стопы лонгистов), над равными максимумами (equal highs, стопы шортистов), у круглых чисел, за краями боковика. «Равные» экстремумы = ровная полка, куда цена идёт снять стопы фитилём и развернуться.

5

Ловушки (твои разобранные ошибки)

Круглое ≠ сильный уровень

Круглое число (нули) ≠ «сильный уровень» (борьба/касания). Круглое — усилитель, а не сам сигнал. Не называть любой заметный уровень «круглым».

Уровень = зона, не нитка

Один тонкий пиксель — иллюзия точности. Веди уровень зоной по кластеру тел; хвосты (фитили) торчат за границу — это норма.

Прокол ≠ пробой

Событие — только по ЗАКРЫТИЮ свечи за уровнем. Длинный фитиль сквозь уровень = снятие ликвидности, а не пробой. Ждём закрытие.

Откат ≠ разворот

Пока структура держит HH + HL (аптренд) — это откат, тренд жив. Разворот начинается только со слома опоры (CHoCH).

✦

Карточка на стену

  • Структура: импульс + коррекция, тренд = лестница. Откат ≠ разворот.
  • Аптренд = HH + HL (🟠, только лонги) · Даунтренд = LH + LL (🟣, только шорты) · Флэт = EQH/EQL.
  • BOS — слом по тренду (продолжение). CHoCH — слом против тренда (1-й признак разворота).
  • Разворот: аптренд → CHoCH (слом HL) → LH → BOS вниз (пробой LL) → даунтренд.
  • Уровень = след крупных денег, ведём зоной. Первое касание сильнее, частые тесты ослабляют.
  • Полярность: пробитый уровень меняет роль (сопротивление ↔ поддержка). Живёт в BOS + ретест.
  • Зона спроса 🟠 — база под импульсом вверх; зона предложения 🟣 — база над импульсом вниз. Свежая зона сильнее.
  • Круглое число — усилитель (магнит/стопы), не синоним сильного уровня.
  • Ликвидность — под equal lows / над equal highs / у круглых / за краями боковика.
  • Событие структуры — по закрытию. Прокол тенью = снятие ликвидности.
