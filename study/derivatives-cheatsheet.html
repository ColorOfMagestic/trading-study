2

Open Interest — сколько позиций открыто

OI = число открытых (ещё не закрытых) контрактов ПРЯМО СЕЙЧАС. Это моментальный снимок «сколько позиций висит на рынке». Нейтрален к направлению — как funding.

Растёт OI = приток новых денег / позиций (в рынок заходят). Падает OI = позиции закрываются (деньги выходят).

OI (снимок)

Сколько контрактов открыто сейчас. Сколько денег реально осталось в рынке.

≠

Volume (за период)

Сколько наторговали за час / день (все сделки туда-сюда). Это активность.

Ключ: volume может быть огромным, а OI не сдвинуться — если открывали и тут же закрывали внутри дня. Volume = активность, OI = сколько убеждённости осталось.

3

4 комбо: цена × OI

Цена ↑ + OI ↑ заходят новые лонги

Новые деньги двигают цену вверх. Тренд подкреплён притоком.

→ здоровый тренд ВВЕРХ 🟠
Цена ↓ + OI ↑ заходят новые шорты

Новые деньги двигают цену вниз. Тренд подкреплён притоком.

→ здоровый тренд ВНИЗ 🟣
Цена ↑ + OI ↓ short covering

Рост на закрытии шортов, а не на новых покупках. Топливо кончается.

→ рост СЛАБЫЙ, выдыхается
Цена ↓ + OI ↓ выход / ликвидация лонгов

Падение на закрытии лонгов, капитуляция. Движение теряет силу.

→ падение выдыхается
Аналогия: цена = куда идёт толпа, OI = толпа растёт или редеет. Движение здорово, когда народа прибавляется (OI↑ в сторону цены).
4

Ликвидации — считай по механике

Ликвидация ЛОНГА

Биржа принудительно закрывает лонг → это принудительная ПРОДАЖА → давит цену.
→ цена ВНИЗ 🟣

Ликвидация ШОРТА

Биржа принудительно закрывает шорт → это принудительная ПОКУПКА → толкает цену.
→ цена ВВЕРХ 🟠
Каскад = цепная реакция: одни ликвидации запускают следующие (движения 3–8% за минуты). Это механизм «топлива против толпы» из funding: сильный + → лонг-ликвидации под ценой → каскад вниз; сильный − → шорт-ликвидации над ценой → squeeze вверх.
5

Liquidation heatmap — магнит, не сигнал

кластер шорт-ликв
 
◀ цена сейчас
 
кластер лонг-ликв

Яркая зона = много плеча = топливо = МАГНИТ: цена тянется туда, чтобы его снять.

Кластер ВЫШЕ цены — там ликвидируются шорты → закрытие = покупка → тянет ВВЕРХ 🟠.

Кластер НИЖЕ цены — там ликвидируются лонги → закрытие = продажа → тянет ВНИЗ 🟣.

Это родня equal highs/lows из 2.4. Используем как ориентир для тейка и понимания «куда тянет» — НЕ как сигнал входа. Модель вероятностная, не грааль.

7

Ловушки терминов

OI ≠ volume

OI ≠ volume. OI — открыто сейчас (снимок); volume — наторговано за период (активность). Большой volume при неизменном OI = гоняли позиции внутри дня.

Рост OI сам по себе не «бычий»

OI нейтрален к направлению. «Новые деньги» ≠ «новые лонги». Смысл только в паре с ценой (4 комбо). При падении рынка растущий OI = скорее новые шорты.

Ликвидация лонгов давит ВНИЗ

Друг: «лонги ликвидируются → вверх, покупаем!» — ошибка. Ликвидация лонга = принудительная продажа → цена вниз. Считай по механике, не по интуиции.

Heatmap = магнит, не команда

Яркий кластер — это куда тянет, а не «входи здесь». Ориентир для тейка и понимания хода. Вход всё равно = свеча на уровне. Модель вероятностная.

Карточка на стену

  • Три прибора ⓪: funding = КУДА толпа, OI = СКОЛЬКО денег, ликвидации/heatmap = ГДЕ топливо.
  • OI = открытые контракты сейчас (снимок). ≠ volume (оборот за период).
  • OI растёт = приток; падает = выход. Нейтрален к направлению.
  • 4 комбо: цена↑+OI↑ = здоровый рост 🟠 · цена↓+OI↑ = здоровое падение 🟣 · OI↓ = движение выдыхается.
  • Ликвидация лонга = принуд. продажа → вниз 🟣. Ликвидация шорта = принуд. покупка → вверх 🟠.
  • Каскад = цепная реакция ликвидаций (3–8% за минуты).
  • Heatmap = магнит: кластер выше → тянет вверх, ниже → вниз. Ориентир, не сигнал.
  • Связь с funding: сильно+ → лонг-ликв под ценой → каскад вниз; сильно− → шорт-ликв над ценой → squeeze вверх.
  • Формула: ⓪ (BTC→доминация→funding→OI/ликвидации) → ① → ② → ③.
  • Инструмент — Coinglass (вкладки Open Interest / Liquidation; Heatmap — отдельная страница).
